# Share Snippets

Create, store, and access your code snippets instantly — with Monaco-powered syntax highlighting, instant share links, and sync across devices via a VS Code extension.

 **Live:** [share-snippets.site](https://www.share-snippets.site/)

 **VS Code Extension:** [Install from Marketplace](https://marketplace.visualstudio.com/items?itemName=Piyush5784.share-snippets-by-Piyush5784)

## Features

- **Syntax Highlighting** — Monaco editor support with 100+ language themes (JavaScript, Python, TypeScript, Go, Rust, Java, and more)
- **Instant Sharing** — share any snippet via a unique link in one click
- **Private & Public Snippets** — full control over visibility
- **Smart Search** — find snippets by language, tags, or keywords in milliseconds
- **Collections & Tags** — organize snippets into custom collections
- **Star Favorites** — bookmark your go-to snippets for quick access
- **User Profiles** — showcase your snippets and build a developer portfolio
- **VS Code Extension** — create and sync snippets without leaving your editor
- **Secure & Encrypted** — enterprise-grade encryption for your code

## Getting Started

1. Sign in with your email at [share-snippets.site](https://www.share-snippets.site/pages/login)
2. Generate your API key from your profile
3. (Optional) Install the [VS Code extension](https://marketplace.visualstudio.com/items?itemName=Piyush5784.share-snippets-by-Piyush5784) for in-editor snippet creation and sync
4. Start creating, tagging, and sharing snippets


## Tech Stack
 
**Web App**
- [Next.js 15](https://nextjs.org/) (React 19, TypeScript)
- [Prisma](https://www.prisma.io/) ORM
- [NextAuth](https://next-auth.js.org/) for authentication
- [Monaco Editor](https://microsoft.github.io/monaco-editor/) for code editing
- [Tailwind CSS](https://tailwindcss.com/) + [Radix UI](https://www.radix-ui.com/) components
- [TanStack Query](https://tanstack.com/query) for data fetching/caching
- [Zustand](https://github.com/pmndrs/zustand) for client state
- [Upstash Redis](https://upstash.com/) + [Upstash Ratelimit](https://github.com/upstash/ratelimit) for rate limiting
- [Zod](https://zod.dev/) + [React Hook Form](https://react-hook-form.com/) for validation and forms
- bcrypt / JWT for auth security
- [Vitest](https://vitest.dev/) for testing

**VS Code Extension**
- TypeScript, bundled with Webpack
- Axios for API communication with the Share Snippets backend
- Published on the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=Piyush5784.share-snippets-by-Piyush5784)
